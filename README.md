# FitVision AI

AI-Based Fitness Monitoring and Exercise Assistance System.

## Modules
- User Registration and Login
- Dashboard
- Exercise Selection
- Camera-based Exercise Monitoring
- Pose Detection
- Posture Analysis
- Repetition Counting
- Real-Time Feedback
- Workout Tracking
- Progress Monitoring

## Technology
React.js, JavaScript, Tailwind CSS, Node.js, Express.js, MediaPipe Pose, Firebase, Git/GitHub.
